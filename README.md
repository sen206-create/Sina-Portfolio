## My Projects (Descending Chronological Order)

### Exploring Schizophrenia Classification with Structural MRI and Support Vector Machines

After working on MRI preprocessing, I wanted to incorporate machine learning into my MRI processing skillset. Inspired by a study on predicting the course of psychosis (Mourao-Miranda et al., 2011), I used SPM and CAT softwares to process structural MRI scans from 175 participants, then trained a support vector machine to distinguish schizophrenia from controls.I also investigated how scan quality and scanner differences affected the results, and whether MRI performed better than a model using basic participant and scan information.

The [project file](Projects/MRI_SVM/schizophrenia-mri-svm.md) includes the workflow, figures, results and R scripts.

 ### Introduction to Neurohacking in R course, Johns Hopkins University

This was from the final course in a 4-course specialisation 'Neuroscience and Neuroimaging'. However, unlike the course I used Ants R package instead of the older packages discussed in the course.

Here I use the ANTs R package to create a MRI preprocessing pipeline that converted T1, T2 and FLAIR DICOM scans to NIfTI, performed N4 bias correction, T1 brain extraction, rigid multimodal registration, mask application and visual quality control to produce aligned brain-only outputs. 

The [project file](Projects/JHU-MRI/brainix-mri-preprocessing.md) includes descriptions of the coding project.
